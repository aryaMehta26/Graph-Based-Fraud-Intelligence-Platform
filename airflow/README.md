# Local Airflow AML demo

This additive Airflow layer mirrors the **lakehouse → Neo4j QA** path shown in the Streamlit dashboard.

What it does (core DAG):
- runs `pipeline_orchestrate.py` → `notebooks/01_data_extraction.py`, `02_data_cleaning.py`, `03_eda_visualizations.py` (with `SKIP_HEAVY_STAGES=1` in Docker to reuse artifacts when present)
- verifies screenshots, parquet splits, model/LLM metrics
- runs `fraud_lakehouse_neo4j_sync.py` (clears `fraudgraph`, loads a sample from Parquet)
- verifies the newest pipeline log contains the expected success markers
- (other DAGs) loads fraud-pattern relationships into Neo4j through `load_fraud_patterns.py`
- (other DAGs) recomputes LLM evaluation metrics from saved artifacts without calling the API again

Default UI:
- URL: `http://localhost:8080`
- Username: `admin`
- Password: generated by Airflow on first startup; retrieve it from the local `airflow/logs/simple_auth_manager_passwords.json` file. Do not commit this file.

Available DAGs:
- `fraud_aml_lakehouse_neo4j_qa_sync`
- `fraud_pattern_loader_demo`
- `llm_artifact_evaluation_demo`
